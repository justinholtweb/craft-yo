Before you write a line

Every plugin
you already have

Yo takes over Craft’s own control panel notices. Thirty installed plugins, none of them changed, all of them in the panel.

1A plugin calls setNotice()The one it has always called
2Yo drains the flash firstBefore the layout renders it, so it never appears twice
3And catches the Ajax ones tooThose never touch the session — they are caught in the browser
4It arrives in the panelTyped, timed, dismissible, and labelled with who sent it

On by default. Turn it off and Craft’s own toasts come straight back.

Receipts

Find out what
became of it

Four events, each carrying the message and the context you set when you sent it — so you can find whatever you were doing at the time.

EventWhat you do with it
SHOWN→It reached a screen
READ→They opened it
DISMISSED→Stop asking
ACTIONED→Retry the import they pressed retry on

A message with a button is a control surface, not a notification.

From the CLI

And from
your deploy script

A console run has no current user, so address it — and Yo says so in the log rather than pretending it went somewhere.

$ php craft yo/say "Deploy finished" --type=success --to=group:editors
Sent to group:editors.
$ php craft yo/channels
cp     Control panel  (queued by Yo)
site   Front end  (queued by Yo)
slack  Slack  (transport)
$ php craft yo/purge
Purged 12 expired messages. Nothing live was touched.
