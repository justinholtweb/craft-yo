# Plugin Store promo images

Marketing images for the Yo listing on the Craft Plugin Store, rendered in the same theme as the
plugin's marketing page at
[justinholt.com/plugins/craft-yo](https://justinholt.com/plugins/craft-yo).

## Building

```bash
./build.sh          # all slides
./build.sh "2 8"    # just slides 2 and 8
```

Output lands in `out/` as `yo-promo-N.png`, 1920×1080 (rendered at 2× in headless Chrome, then
downsampled so the type stays crisp).

## Slides

| # | Slide | Shows |
|---|-------|-------|
| 1 | Cover — name, tagline, app icon, free | — |
| 2 | one page load → until answered | the whole pitch, in two lines |
| 3 | Say it once, properly | five types, dedupe, buttons |
| 4 | Every plugin you already have | how adoption works, in four steps |
| 5 | Add a channel, reach everything | the channel registry, and the fourth one being yours |
| 6 | Find out what became of it | the four receipt events and what to do with each |
| 7 | And from your deploy script | console output |
| 8 | The panel, in context | a real control panel screenshot |
| 9 | The dashboard widget | a real control panel screenshot |
| 10 | Settings | a real control panel screenshot |

Slides 1–7 are pure CSS and type. Slides 8–10 are control-panel screenshot cards; the captures live
in `shots/` and are taken with the harness at `~/Sites/plugin-shots`:

```sh
cd ~/Sites/plugin-shots
node capture.mjs /tmp/yoshots spec.json
```

**The panel is `position: fixed`, and that harness hides every fixed `body > div` that is not
control panel chrome.** Its spec already accepted a `keep` key but never implemented it — that was
added while building this deck, so `"keep": ["#yo-panel"]` now works. Without it the panel is
invisible in every shot and the screenshots quietly become pictures of somebody else's dashboard.

A tall or portrait capture needs `class="cpc-frame cpc-clip"` on its figure, or the image runs
straight off the card.

## Editing

Everything lives in `slides.html` — one `<section class="slide">` per image. The palette is the
app icon's: cool-white `#eaf6ff` line art over steel blue `#33608a`, on a navy ground, with
`#7aa2c8` doing the accent work. Jersey 20 for display, Inter for body.

The tokens are in `:root`. `--accent`, `--accent-light` and `--off-white` keep those names on
purpose — the control-panel screenshot cards at the bottom of the stylesheet are shared with the
family's other decks and reach for exactly those three, so renaming them breaks the cards
everywhere else.

`assets/` holds the fonts and two icon files:

- `icon.svg` — the app icon, used for the cover mark and the footer lockup. Copy it from
  `../src/icon.svg` whenever the icon changes.
- `watermark.svg` — the alien with the tile stripped. The tile is a solid rounded square and at
  watermark scale it reads as a grey box across the slide rather than as a mark. Its viewBox is
  cropped to the drawing's own bounds so the line art fills the watermark box instead of floating
  in the tile's padding, and it sits at `opacity: 0.04` rather than the marigold deck's `0.05`:
  that watermark was four solid shapes, this one is open line work, and line work of that density
  reads louder at the same alpha.

`fonts.css` is generated by `build.sh` (the woff2 files are base64-inlined so Chrome's `file://`
origin rules can't block them) and is not checked in.
